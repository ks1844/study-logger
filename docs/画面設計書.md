
# 画面仕様書（study-logger）

## 画面一覧（ページとして存在するもの）

| 画面ID          | 画面名         | URL          | 説明 |
|-----------------|----------------|--------------|------|
| login           | ログイン       | /login       | ユーザーがアプリにログインする |
| dashboard       | ダッシュボード | /dashboard   | 学習状況の概要を確認し、学習記録一覧とカテゴリ一覧を開く中心 |
| studyrecord-list| 学習記録一覧   | /studyrecord | 学習記録を一覧で確認し、作成・編集モーダルを開く |
| category-list   | カテゴリ一覧   | /category    | カテゴリを一覧で確認し、カテゴリの作成・編集モーダルを開く |

## モーダル一覧（操作として存在するもの）

| モーダルID               | モーダル名           | 開く場所     | 説明 |
|--------------------------|----------------------|--------------|------|
| studyrecord-create-modal | 学習記録作成モーダル | /studyrecord | 新しい学習記録を登録する |
| studyrecord-edit-modal   | 学習記録編集モーダル | /studyrecord | 既存の学習記録を編集・削除する |
| category-create-modal    | カテゴリ作成モーダル | /category    | 新しいカテゴリを登録する |
| category-edit-modal      | カテゴリ編集モーダル | /category    | 既存のカテゴリを編集・削除する |
| dailyreport-create-modal | 日報作成モーダル     | /dashboard   | 新しい日報を登録する |
| dailyreport-edit-modal   | 日報編集モーダル     | /dashboard   | 既存の日報を編集・削除する |
| pr-generate-modal        | PR生成モーダル       | /dashboard   | 学習内容から PR 文を生成する |
| pr-edit-modal            | PR編集モーダル       | /dashboard   | 既存の PR 文を編集・削除する |

# 画面設計

## login（ログイン画面）
ユーザーがアプリにログインするための画面。

### URL
/login

### 表示項目
- タイトル：ログイン
- メールアドレス入力欄
- パスワード入力欄
- ロール選択
- ログインボタン

### 入力項目

| 項目名         | 型     | 必須 | 説明 |
|----------------|--------|------|------|
| メールアドレス | string | ○    | ログインIDとして使用 |
| パスワード     | string | ○    | ハッシュ化して認証 |

### 操作
- ログインボタン  
  - 認証成功 → `/dashboard` へ遷移  
  - 認証失敗 → エラーメッセージ表示

---

## dashboard（ダッシュボード）
学習状況の概要を確認し、各一覧画面や生成モーダルを開く中心画面。

### URL
/dashboard

### 表示項目
- 今日の学習時間
- 今月の学習時間
- 最近の学習記録（数件）
- ボタン：
  - 学習記録一覧へ
  - カテゴリ一覧へ
  - 日報一覧へ

### 入力項目
なし

### 操作
- 学習記録一覧へ遷移 → `/studyrecord`
- カテゴリ一覧へ遷移 → `/category`
- 日報一覧へ遷移 → `/dailyreport`

---

## studyrecord-list（学習記録一覧）
学習記録を一覧で確認し、作成・編集モーダルを開く画面。

### URL
/studyrecord

### 表示項目
- 学習記録一覧（テーブル）
  - 日付
  - カテゴリ
  - 学習時間
  - メモ（省略表示）
  - 編集ボタン
- 新規作成ボタン

### 入力項目
なし（モーダルで入力）

### 操作
- 新規作成ボタン → `studyrecord-create-modal` を開く
- 編集ボタン → `studyrecord-edit-modal` を開く

---

## category-list（カテゴリ一覧）
カテゴリを一覧で確認し、作成・編集モーダルを開く画面。

### URL
/category

### 表示項目
- カテゴリ一覧（テーブル）
  - カテゴリ名
  - 編集ボタン
- 新規作成ボタン

### 入力項目
なし（モーダルで入力）

### 操作
- 新規作成ボタン → `category-create-modal` を開く
- 編集ボタン → `category-edit-modal` を開く

# モーダル設計

## 学習記録作成モーダル：studyrecord-create-modal
新しい学習記録を登録するモーダル。

### 開く場所
/studyrecord

### 表示項目
- 日付入力欄
- カテゴリ選択
- 学習時間入力欄
- メモ入力欄
- 登録ボタン

### 入力項目

| 項目名   | 型     | 必須 | 説明 |
|----------|--------|------|------|
| 日付     | date   | ○    | 学習した日付 |
| カテゴリ | int    | ○    | カテゴリID |
| 学習時間 | number | ○    | 時間（h） |
| メモ     | string | 任意 | 補足内容 |

### 操作
- 登録ボタン → 新規保存

---
