# 学習記録アプリ 操作手順書（モーダル版・デモ用）

## デモ用アカウント情報
- 学習者（Student）
  - メール: student@example.com
  - パスワード: password
- 管理者（Manager）
  - メール: admin@example.com
  - パスワード: password

## ログイン
1. ログイン画面を開く  
2. メールアドレスとパスワードを入力  
3. 「ログイン」ボタンをクリック  
4. 正常にログインすると ダッシュボード に遷移

---

## 学習カテゴリ管理（学習者のみ）
1. ダッシュボードから「カテゴリ一覧」を開く  
2. カテゴリ作成モーダルを開く  
   - 「カテゴリ作成」ボタンをクリック  
   - カテゴリ名を入力し「保存」  
3. カテゴリ編集モーダルを開く  
   - 一覧の「編集」ボタンをクリック  
   - 名称を変更して「保存」  
4. 削除（論理削除）  
   - 編集モーダル内の「削除」ボタンをクリック  

※カテゴリ画面ではページ遷移せず、すべてモーダルで操作可能。

---

## 学習記録
1. 「学習記録」画面を開く  
2. 学習記録作成モーダルを開く  
   - 「記録作成」ボタンをクリック  
   - 日付、カテゴリ、学習時間、メモを入力  
   - 「保存」をクリック  
3. 学習記録編集モーダルを開く  
   - 一覧の「編集」ボタンをクリック  
   - 内容を変更して「保存」  
4. 削除（論理削除）  
   - 編集モーダル内の「削除」ボタンをクリック  

※記録の追加・編集・削除はすべてモーダルで完結。

---

## 日報
日報は ダッシュボード から操作する仕様。

1. ダッシュボードで「日報作成」ボタンをクリック  
2. 日報作成モーダルが開く  
   - 日付を選択  
   - 目標・達成・苦戦・乗り越え方を入力  
   - 「保存」をクリック  
3. 既存の日報を編集する場合  
   - ダッシュボードの一覧から対象日報の「編集」ボタンをクリック  
   - 日報編集モーダルが開く  
   - 内容を変更して「保存」  
4. 削除（論理削除）  
   - 編集モーダル内の「削除」ボタンをクリック  

---

## ダッシュボード
- ログイン後に表示されるメイン画面  
- 以下の情報を確認可能  
  - 今日の学習時間  
  - 今月の学習時間  
  - 最近の学習記録  
- 以下の操作が可能  
  - 「学習記録一覧」へ移動  
  - 「カテゴリ一覧」へ移動  
  - 「日報一覧」へ移動

---

## 管理者機能
1. 管理者アカウントでログイン  
2. 「学習者一覧」画面を開く  
3. 所属会社の学習者の学習状況を閲覧可能  
4. 学習者を選択すると、個別データを確認できる  

※管理者側の編集機能は必要に応じて追加可能。
